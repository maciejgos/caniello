# Features

Use this directory for optional lightweight feature briefs shaped from broad notes, discovery findings, or product ideas that are too large for one task.

Feature briefs are not a required gate before implementation. Use them only when they clarify scope, tradeoffs, and candidate tasks.

Create one Markdown file per lightweight feature brief using `LIGHTWEIGHT_TEMPLATE.md`. Historical detailed feature definitions are archived under `spec/archive/flow-forge-history/`.
