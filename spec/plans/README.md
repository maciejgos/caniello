# Plans

Use this directory for self-contained Codex ExecPlans that guide significant implementation work. `PLANS.md` is the authoritative format and maintenance guide.

Active plans should remain specific, living handoffs for work that can still be resumed. When a plan is complete and no longer the active implementation path, consolidate it into a short historical summary instead of keeping obsolete step-by-step instructions in the main planning surface.

Current rollups:

- `completed-foundation-plans.md`: historical summary for the first landing page and Next.js monorepo migration plans.
