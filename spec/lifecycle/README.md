# Lifecycle

Use this directory for post-release retrospectives, incident learnings, feedback reviews, operational observations, and continuous improvement notes.

Lifecycle artifacts close the PDLC loop by turning real-world evidence into routed follow-up. Do not restart at requirements by default; route each learning to the earliest PDLC stage that actually needs to change.

Create one focused Markdown file per active retrospective or learning review using `TEMPLATE.md`. Consolidate older reflections when they cover the same product slice and no longer need separate operational handling.

Current rollups:

- `landing-page-lifecycle-history.md`: consolidated landing-page process and public-validation learnings.
